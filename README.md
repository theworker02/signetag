# signetag

Sign CSV/TSV etag tables for quick inspection and cleanup.

**Site:** https://theworker02.github.io/signetag/

## Install / run

```bash
git clone https://github.com/theworker02/signetag.git
cd signetag
node src/cli.js
node --test
```
